Bookmarklets & Scripts

Userscripts

Userscripts are what Tampermonkey calls content scripts in the Chrome extension ecosystem. Tampermonkey allows you to write up a script that would work as a content script without the need to create a new extension for every script. Usually I write these when I find something I don't like on a website I regularly interact with. Most of them are work related and are meant to be discarded.
